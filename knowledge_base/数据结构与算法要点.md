# 数据结构与算法要点

## 1. 复杂度分析
- 时间复杂度描述运行时间随数据规模的增长趋势，用大 O 表示。
- 常见量级（由快到慢）：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)。
- 空间复杂度同理，关注额外使用的内存。
- 分析原则：只保留最高阶项、忽略常数系数；关注最坏情况与平均情况。

## 2. 线性结构
- 数组：随机访问 O(1)，中间插入删除 O(n)。
- 链表：插入删除 O(1)（已知位置），查找 O(n)；单链表、双链表。
- 栈（stack）：后进先出（LIFO），用于括号匹配、函数调用、撤销操作。
- 队列（queue）：先进先出（FIFO），用于任务调度、广度优先搜索。
- 双端队列（deque）：两端都能进出。

## 3. 哈希表
- 原理：用哈希函数把 key 映射到桶，平均查找/插入 O(1)。
- 冲突处理：链地址法、开放寻址法。
- 扩容：负载因子过高时扩容并重新哈希。
- 应用：缓存、计数、去重、字典。
- 注意：哈希表无序；最坏情况退化为 O(n)。

## 4. 树
- 二叉树：每个节点最多两个子节点。
- 遍历方式：前序（根左右）、中序（左根右）、后序（左右根）、层序（BFS）。
- 二叉搜索树（BST）：左 < 根 < 右，平均查找 O(log n)，退化成链表时 O(n)。
- 平衡树：AVL、红黑树，保证树高 O(log n)（Java 的 TreeMap、C++ 的 std::map）。
- 堆：完全二叉树，大顶堆/小顶堆，取最值 O(1)，插入删除 O(log n)，常用于优先队列与 Top-K。

## 5. 图
- 表示方式：邻接矩阵（稠密图）、邻接表（稀疏图）。
- 遍历：BFS（队列，求最短路径步数）、DFS（递归/栈，连通性判断）。
- 常见问题：最短路径（Dijkstra、Floyd）、最小生成树（Prim、Kruskal）、拓扑排序（有向无环图）。
- 有向图与无向图、带权图与无权图。

## 6. 排序算法对比
| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|---------|---------|------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |

- 快排优化：随机选基准、三路划分；小数组用插入排序。
- 工程实践通常直接使用语言内置排序（Python `sorted`、Java `Arrays.sort`），底层多为混合算法（如 Timsort）。

## 7. 查找
```python
def binary_search(nums, target):
    """有序数组二分查找，返回下标，找不到返回 -1"""
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```
- 二分查找前提是数据有序，复杂度 O(log n)。
- 变体：找第一个/最后一个等于目标的位置（边界处理是关键）。

## 8. 常用算法思想
- 双指针：有序数组求和、去重、链表判环。
- 滑动窗口：连续子数组/子串的最值问题。
- 分治：归并排序、快速排序、二分查找。
- 贪心：每一步取局部最优（活动选择、找零），需证明最优子结构。
- 动态规划：重叠子问题 + 最优子结构，用状态定义 + 转移方程 + 边界，如背包、最长公共子序列、编辑距离。
- 回溯：穷举所有可能并剪枝，如全排列、N 皇后、组合求和。
- 位运算：状态压缩、判断奇偶、快速幂。

## 9. 经典题目示例
```python
def two_sum(nums, target):
    """两数之和：返回两个下标"""
    seen = {}
    for index, value in enumerate(nums):
        if target - value in seen:
            return [seen[target - value], index]
        seen[value] = index
    return []


def reverse_list(head):
    """反转单链表"""
    prev = None
    while head:
        nxt = head.next
        head.next = prev
        prev = head
        head = nxt
    return prev
```

## 10. 学习建议
- 先掌握数组、字符串、哈希表、链表、栈队列，再学树图与动态规划。
- 按题型分类刷题（每个题型 5~10 题），总结模板与易错点。
- 做题流程：理解题意 → 写暴力解 → 分析复杂度 → 优化 → 处理边界 → 复盘。
- 常见边界：空输入、单元素、重复元素、越界、整数溢出。
