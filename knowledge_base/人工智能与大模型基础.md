# 人工智能与大模型基础

## 1. 人工智能、机器学习、深度学习的关系
- 人工智能（AI）：让机器完成需要智能的任务的总称。
- 机器学习（ML）：AI 的一个分支，让程序从数据中自动学习规律，而不是靠人写死规则。
- 深度学习（DL）：机器学习的分支，使用多层神经网络，擅长图像、语音、自然语言等复杂任务。

## 2. 机器学习的三大类型
- 监督学习：训练数据带标签，如分类（判断邮件是否为垃圾邮件）、回归（预测房价）。
- 无监督学习：数据无标签，如聚类（用户分群）、降维（PCA）。
- 强化学习：智能体通过与环境交互、根据奖励信号学习策略，如游戏 AI、机器人控制。

## 3. 神经网络基础
- 神经元：对输入做加权求和后经过激活函数输出。
- 常用激活函数：ReLU、Sigmoid、Tanh、Softmax（多分类输出）。
- 损失函数：衡量预测与真实值的差距，如交叉熵（分类）、均方误差（回归）。
- 训练过程：前向传播计算输出 → 计算损失 → 反向传播求梯度 → 用梯度下降更新参数。
- 过拟合与正则化：Dropout、L1/L2 正则、早停、数据增强。
- 常用优化器：SGD、Adam、AdamW。

## 4. Transformer 与注意力机制
- 注意力机制：让模型在处理某个词时，自动关注句子中其他相关的词。
- 自注意力（Self-Attention）：序列内部各位置互相计算相关性。
- 多头注意力：从多个子空间并行学习不同的关注关系。
- Transformer 结构：由编码器和解码器堆叠而成，每层包含注意力子层和前馈网络，配合残差连接与层归一化。
- 位置编码：因为注意力本身不包含顺序信息，需要额外注入位置。
- 优势：并行计算效率高，能捕捉长距离依赖，是当前大语言模型的基础结构。

## 5. 大语言模型（LLM）
- 本质：用海量文本训练的超大参数量的 Transformer 模型，目标是预测下一个 token。
- 训练三阶段：预训练（学习通用语言能力）→ 指令微调 SFT（学会听懂指令）→ 对齐（RLHF/DPO，让输出更符合人类偏好）。
- token：模型处理文本的最小单位，中文一般 1 个汉字约 1~2 个 token。
- 上下文窗口：模型一次能看到的 token 上限，超出部分会被截断。
- 温度（temperature）：控制随机性，0 附近更确定，1 附近更有创造性。
- 常见开源模型：Qwen（通义千问）、Llama、DeepSeek、Mistral、GLM。
- 常见闭源模型：GPT 系列、Claude 系列、Gemini 系列。

## 6. RAG（检索增强生成）
- 定义：先从知识库检索相关内容，再把检索结果作为上下文交给大模型生成回答。
- 流程：文档切块 → 向量化存入向量数据库 → 用户提问时检索最相关片段 → 拼提示词 → 模型生成答案。
- 优点：知识可随时更新、回答有出处、减少幻觉、不需要重新训练模型。
- 与微调的区别：微调改变模型参数，成本高、更新慢；RAG 只改外部知识库，成本低、更新快。二者可以结合使用。
- 关键影响因素：切块大小、向量模型质量、检索策略（向量/关键词/混合）、重排序（rerank）。

## 7. 提示词工程（Prompt Engineering）
- 明确角色与任务："你是一个……请完成……"
- 给出约束：输出格式、长度、语言、不能编造。
- 提供示例（少样本提示，Few-shot）。
- 复杂任务分步思考（思维链，Chain-of-Thought）。
- 结构化输出：要求返回 JSON，便于程序解析。
- 常见技巧：先总结再回答、让模型自查、把长文档分段处理。

## 8. AI Agent 与工具调用
- Agent：让大模型自主决定调用哪些工具（搜索、计算、数据库、代码执行）来完成任务。
- Function Calling / Tool Calling：模型输出结构化的工具调用请求，程序执行后把结果回传。
- 常见模式：ReAct（推理+行动交替）、规划-执行、多智能体协作。
- 风险：工具调用错误、循环调用、权限与安全边界。

## 9. 评价指标与常见问题
- 分类：准确率、精确率、召回率、F1。
- 生成：BLEU、ROUGE（偏文本重合）、人工评价、LLM 打分。
- 检索：命中率（Recall@k）、MRR、NDCG。
- 幻觉：模型编造事实，缓解手段是 RAG、提示词约束、降低温度、事实核查。
- 其他问题：上下文长度限制、推理成本、数据隐私、偏见与安全。
